# Módulo 4: Ciclo de desarrollo

## Objetivo

Al final de este módulo, vas a:
- ver el camino completo de un cambio, desde el ticket hasta que está en línea;
- escribir una tarea clara, con lo que cuenta como "terminado";
- dividir una tarea en pasos pequeños, con la ayuda de la IA;
- hacer el trabajo en una rama y probarlo antes de pedir revisión;
- hacer el merge, comprobar el resultado y cerrar el ciclo;
- organizar un backlog y decidir qué va primero.

El camino principal sigue siendo en la computadora, con GitHub Codespaces. Las issues, los pull requests y los tableros de proyecto funcionan en el sitio web de GitHub, así que cada lección tiene un camino **Desde la tableta o el teléfono**, con los límites explicados.
