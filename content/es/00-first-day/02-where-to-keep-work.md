# 0.2 ¿Dónde guardo mi trabajo?

## Problema

Cambiaste un documento 5 veces. Ahora tu jefe quiere la versión del martes, pero guardaste encima. ¿Y ahora qué?

*Piensa: ¿cómo lo evitarías la próxima vez?*

## Bloques

### 1. El problema de las versiones
"documento_final.docx", "documento_final_v2.docx", "documento_final_AHORA_SI.docx"... A todos nos ha pasado. Se vuelve difícil saber cuál es la versión correcta, qué cambió y cuándo.

> **Notas para el tutor:** pregunta si al estudiante le ha pasado. A casi todo el mundo le ha pasado, y eso crea conexión con el tema.

### 2. Control de versiones
El control de versiones es un sistema que guarda **cada cambio** que haces, con la fecha, el autor y una explicación. Puedes volver a cualquier versión anterior cuando quieras.

> **Notas para el tutor:** analogía: es como el historial de versiones de Google Docs, pero mucho más organizado y pensado para equipos.

### 3. Qué es GitHub
GitHub es un sitio web donde los equipos guardan código (y otros archivos) con control de versiones. Es como un Google Drive para código, pero con el historial completo y herramientas para trabajar en equipo.

> **Notas para el tutor:** la diferencia entre Git (la herramienta) y GitHub (el sitio web) queda para más adelante. Aquí basta con saber que GitHub guarda el trabajo con su historial.

### 4. Por qué lo usan todos los equipos
En GitHub, varias personas trabajan en el mismo proyecto sin estropear el trabajo de las demás. Y todo queda público (o visible para el equipo): quién hizo qué y cuándo. Tu perfil de GitHub se convierte en tu currículum de verdad.

> **Notas para el tutor:** destaca el lado profesional: los reclutadores miran GitHub.

## Misión

1. Crea tu cuenta en [GitHub](https://github.com/signup). La interfaz de GitHub está en inglés; en el curso usamos los mismos nombres de botones que verás allí.
2. Pon una foto y escribe una bio corta en inglés (con una frase basta).
3. Envía al tutor el enlace de tu perfil.

**Cómo lo revisa el tutor:** el perfil existe y tiene foto y bio.
