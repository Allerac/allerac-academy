# 0.3 Mi primer repositorio

## Problema

Quieres guardar lo que estás aprendiendo y dejar que otra persona lo vea y te sugiera mejoras. ¿Dónde lo guardarías?

## Bloques

### 1. Qué es un repositorio
Un repositorio (o "repo") es la carpeta de un proyecto en GitHub. Guarda los archivos y todo el historial de cambios.

> **Notas para el tutor:** analogía: una carpeta con memoria. Recuerda todo lo que ha estado alguna vez dentro de ella.

### 2. Qué es un README
El README es el archivo de presentación del repositorio. Es lo primero que alguien ve al abrir el proyecto: qué es, para qué sirve y cómo se usa.

> **Notas para el tutor:** muestra el README de allerac-academy como ejemplo real.

### 3. Qué es un commit
Un commit es una "foto" del trabajo en un momento dado, con un mensaje que explica qué cambió. El historial del repositorio es la lista de todos sus commits.

Un buen mensaje de commit es corto y dice lo que hiciste: "Add introduction to README", y no "cambios".

> **Notas para el tutor:** los mensajes de commit van en inglés, como todo lo demás en el código. Error común: mensajes vagos como "update" o "fix".

### 4. Por qué en inglés
En el mundo del software, el código y su documentación se escriben en inglés, para que cualquier persona del mundo los entienda. No necesitas hablarlo con fluidez: la IA te ayuda.

> **Notas para el tutor:** tranquiliza al estudiante. Anímalo a usar la IA para revisar su inglés.

## Misión

1. Crea un repositorio llamado `my-academy-journal` y marca la opción para añadir un README (**Add a README file**).
2. Edita el README desde el navegador y escribe 3 líneas en inglés sobre ti y por qué estás haciendo el curso (puedes pedirle ayuda a la IA).
3. Guárdalo con un commit que tenga un mensaje claro, por ejemplo `Add introduction to README`.
4. Envía al tutor el enlace del repositorio.

**Cómo lo revisa el tutor:** el repositorio existe, el README tiene 3 líneas en inglés y el commit tiene un mensaje claro.
