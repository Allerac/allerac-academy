# Módulo 3: Colaboración

## Objetivo

Al final de este módulo, vas a:
- escribir commits que cuentan qué cambió y por qué;
- trabajar en una rama (branch) sin tocar la versión que funciona;
- abrir un pull request, revisar y recibir una revisión con amabilidad;
- resolver un conflicto con la ayuda de la IA, decidiendo tú el resultado;
- leer código que no escribiste, con la IA explicándolo;
- abrir tu primer pull request de verdad en un proyecto de Allerac.

El camino principal sigue siendo en la computadora, con GitHub Codespaces. Casi todo en este módulo también funciona en el sitio web de GitHub, así que cada lección tiene un camino **Desde la tableta o el teléfono**, con los límites explicados.
