# 1.4 ¿Chat o agente?

## Problema

Tienes una carpeta con 200 fotos llamadas "IMG_0001.jpg", "IMG_0002.jpg"... y quieres renombrarlas todas con la fecha. Pides ayuda en un chat de IA. Te da instrucciones. Pero ¿quién va a renombrar las 200 fotos?

## Bloques

### 1. El chat responde
En un chat, la IA te da texto: una explicación, un correo, un fragmento de código. Quien copia, pega y ejecuta eres tú.

> **Notas para el tutor:** es lo que el estudiante ya hizo en las lecciones anteriores.

### 2. El agente hace
Un agente es una IA que puede usar herramientas: leer y crear archivos, ejecutar comandos, buscar. Tú describes el objetivo y él ejecuta los pasos, revisa el resultado y corrige si algo sale mal.

> **Notas para el tutor:** analogía: el chat es un compañero que te explica por teléfono cómo hacerlo. El agente es un compañero que se sienta frente a tu computadora y lo hace mientras tú miras.

### 3. Agentes de código
Claude Code y Codex son agentes hechos para programar. Leen los archivos del proyecto, escriben código, ejecutan pruebas y explican lo que hicieron. Con ellos vas a trabajar en los proyectos de Allerac.

> **Notas para el tutor:** el estudiante va a instalar y usar un agente de código en el módulo 2. Aquí es solo el concepto. No lo confundas con el chat de Claude.

### 4. Más poder, más cuidado
Un agente cambia de verdad tus archivos. Por eso:
- Pídele que explique su plan antes de hacer nada.
- Revisa lo que cambió.
- Trabaja con control de versiones (GitHub), para poder volver atrás.

> **Notas para el tutor:** conéctalo con el módulo 0: el historial de GitHub es la red de seguridad para trabajar con agentes.

## Misión

Para cada tarea de abajo, dile al tutor si basta con un chat o si sería mejor un agente, y por qué:
1. Escribir una invitación de cumpleaños.
2. Corregir un error que aparece en 15 archivos de un proyecto.
3. Entender qué significa un mensaje de error.
4. Crear un sitio web de 5 páginas y publicarlo.

**Cómo lo revisa el tutor:** el estudiante identifica que las tareas que tocan muchos archivos o requieren ejecutar cosas piden un agente (2 y 4), y lo justifica.
