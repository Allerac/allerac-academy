# 2.1 Where things live

## Problem

You saved a file a moment ago, closed the window and... it is gone. Is it in Downloads? On the Desktop? In a folder whose name you do not remember? How would you explain exactly where it is, so someone else could find it?

*Try to think of an answer before you go on.*

## Blocks

### 1. Files live in folders
A file is a piece of information with a name: a text, a photo, your `index.html` page. A folder (also called a directory) is a place to group files. When a file "disappears", it is almost always in a folder you are not looking at.

> **Tutor notes:** almost everyone has lost a file. Use that experience. Do not start with paths yet.

### 2. Folders inside folders
Folders can have other folders inside them. Like boxes inside boxes, or rooms inside a house. Your `my-academy-journal` repository is a folder: inside it are `README.md` and `index.html`.

> **Tutor notes:** use the house or boxes analogy. If the student has already created subfolders on their phone or computer, connect it to that.

### 3. The extension tells you the type
The part after the dot in a file name is the extension. It hints at what the file is:
- `.md` is Markdown text (like the README)
- `.html` is a web page
- `.jpg` or `.png` is an image
- `.txt` is plain text

In the software world, file names and extensions are in English. You do not need to memorize a list: when in doubt, ask AI what an extension means.

> **Tutor notes:** stress that the extension is part of the name, not decoration. Common mistake: deleting or changing the extension and the file "breaking". Do not go into MIME types.

### 4. The path is the address
A path is the full address of a file: the sequence of folders, from the "house" to the room to the object. For example, in your repository, the path of the page file is `index.html` (it is in the main folder). If it were in a `pages` folder, the path would be `pages/index.html`.

The slashes separate the folders. That is how you (and the computer, and AI) find things.

> **Tutor notes:** show the path on GitHub: when you open a file, the trail at the top (repository / file) is the path. No need to explain absolute vs relative paths now, unless the student asks. On GitHub the slash is always `/`.

## Mission

1. Open your `my-academy-journal` repository on GitHub (on a computer, tablet or phone).
2. List the files you see in the main folder.
3. Write down the path of `index.html` and say what the `.md` and `.html` extensions mean.
4. Tell the tutor, in your own words, how you would explain to someone where that file lives.

**How the tutor checks:** the student lists the repository's files, gets the path of `index.html` right and explains, even simply, what the two extensions are.
