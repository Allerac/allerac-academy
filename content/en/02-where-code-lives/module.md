# Module 2: Setup and where code lives

## Goal

By the end of this module, you will:
- know what files, folders, extensions and paths are;
- use the basic terminal commands safely (asking AI to explain before you run anything);
- open your `my-academy-journal` repository in a code editor;
- change your page with AI's help, see the result and save the new version;
- know what never to paste into an AI, and have turned on two-factor authentication on GitHub.

The main path is on a computer, with the editor in the browser (GitHub Codespaces), with nothing to install. VS Code on your computer is optional.

If you are on a tablet or a phone, you can follow along: lessons 2.2, 2.3 and 2.4 have an alternative path marked **On a tablet or phone**. On a tablet, Codespaces works in the browser (best with a keyboard). On a phone the screen is cramped, so we use GitHub's editor and github.dev, and we are honest about what you cannot do there (for example, github.dev has no terminal).
