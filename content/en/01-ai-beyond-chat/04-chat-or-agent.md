# 1.4 Chat or agent?

## Problem

You have a folder with 200 photos called "IMG_0001.jpg", "IMG_0002.jpg"... and you want to rename them all with the date. You ask an AI chat for help. It gives you instructions. But who is going to rename the 200 photos?

## Blocks

### 1. A chat answers
In a chat, the AI gives you text: an explanation, an email, a piece of code. You are the one who copies, pastes and runs it.

> **Tutor notes:** this is what the student has already done in the previous lessons.

### 2. An agent does
An agent is an AI that can use tools: read and create files, run commands, search. You describe the goal, and it carries out the steps, checks the result and fixes things if they go wrong.

> **Tutor notes:** analogy: a chat is a coworker explaining over the phone how to do it. An agent is a coworker who sits at your computer and does it while you watch.

### 3. Coding agents
Cursor Agent, Claude Code and Codex are examples of coding agents. They can read project files, propose changes and run tests. Module 2 includes an optional Cursor path.

> **Tutor notes:** Use a concrete example: in chat, the student pastes a snippet. In an editor with an agent, the student can point to a project file and review the diff.

### 4. More power, more care
An agent really changes your files. So:
- Ask it to explain its plan before doing anything.
- Review what it changed.
- Work with version control (GitHub), so you can go back.

> **Tutor notes:** connect it to module 0: GitHub's history is the safety net for working with agents.

## Mission

For each task below, tell the tutor whether a chat is enough or an agent would be better, and why:
1. Writing a birthday invitation.
2. Fixing a bug that shows up in 15 files of a project.
3. Understanding what an error message means.
4. Building a 5-page website and publishing it.

**How the tutor checks:** the student sees that tasks that touch many files or require running things call for an agent (2 and 4), and explains why.
