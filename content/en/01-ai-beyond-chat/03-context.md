# 1.3 Context: the conversation's memory

## Problem

In a long conversation with AI, you explained right at the start that the text was for children. Twenty messages later, it writes with difficult words. Did it forget?

## Blocks

### 1. What context is
Context is everything the AI "sees" at that moment: your messages, its replies, and any files you sent. It only knows what is in the context.

> **Tutor notes:** analogy: a work desk. The AI only works with what is on top of the desk.

### 2. Context has a limit
The desk has a size. In very long conversations, older parts can lose weight or drop off. That is why it sometimes "forgets" something from the beginning.

> **Tutor notes:** the technical name is "context window". Mention the name once, without going into detail.

### 3. A new conversation does not remember the last one
Every conversation starts with an empty desk. If you need something from an old conversation, bring it back in.

> **Tutor notes:** some tools have "memory" or "projects" that keep information between conversations. Mention it as an exception, without going deep.

### 4. Giving good context
- Put the most important thing first.
- Send files and examples instead of describing them.
- For new tasks, start a new conversation.
- If it gets lost, remind it of the goal.

> **Tutor notes:** this will be essential with coding agents, which read the project's files as context.

## Mission

1. Start a new conversation in Claude and ask for a short text about a topic you like.
2. Start another conversation and ask: "What was the text you wrote about?"
3. Tell the tutor what happened and why.

**How the tutor checks:** the student explains that each conversation has its own context.
