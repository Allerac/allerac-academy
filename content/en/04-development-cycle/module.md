# Module 4: Development cycle

## Goal

By the end of this module, you will:
- see the whole path of a change, from ticket to live;
- write a clear task, with what counts as "done";
- break a task into small steps, with AI's help;
- do the work on a branch and test it before asking for review;
- merge, check the result and close the loop;
- organize a backlog and decide what comes first.

The main path is still on a computer, with GitHub Codespaces. Issues, pull requests and project boards work on the GitHub website, so every lesson has an **On a tablet or phone** path, with the limits explained.
