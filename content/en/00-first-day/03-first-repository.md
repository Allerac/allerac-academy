# 0.3 My first repository

## Problem

You want to keep track of what you are learning and let someone else see it and suggest improvements. Where would you keep it?

## Blocks

### 1. What a repository is
A repository (or "repo") is a project's folder on GitHub. It keeps the files and the whole history of changes.

> **Tutor notes:** analogy: a folder with a memory. It remembers everything that has ever been inside it.

### 2. What a README is
The README is the repository's welcome file. It is the first thing someone sees when they open the project: what it is, what it is for and how to use it.

> **Tutor notes:** show the allerac-academy README as a real example.

### 3. What a commit is
A commit is a "snapshot" of the work at a certain moment, with a message explaining what changed. The repository's history is the list of all its commits.

A good commit message is short and says what you did: "Add introduction to README", not "changes".

> **Tutor notes:** commit messages are in English, like everything else in the code. Common mistake: vague messages like "update" or "fix".

### 4. Why in English
In the software world, code and code documentation are written in English, so anyone in the world can understand them. You do not need to be fluent: AI helps.

> **Tutor notes:** reassure the student. Encourage them to use Claude to check their English.

## Mission

1. Create a repository called `my-academy-journal`, ticking the option to add a README.
2. Edit the README in the browser and write 3 lines in English about yourself and why you are taking this course (you can ask Claude for help).
3. Save it with a commit that has a clear message, for example `Add introduction to README`.
4. Send the tutor the link to the repository.

**How the tutor checks:** the repository exists, the README has 3 lines in English and the commit has a clear message.
