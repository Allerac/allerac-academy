# Module 3: Collaboration

## Goal

By the end of this module, you will:
- write commits that say what changed and why;
- work on a branch without touching the version that works;
- open a pull request, review, and receive a review kindly;
- resolve a conflict with AI's help, while you decide the result;
- read code you did not write, with AI explaining it;
- open your first real pull request on an Allerac project.

The main path is still on a computer, with GitHub Codespaces. Almost everything in this module also works on the GitHub website, so every lesson has an **On a tablet or phone** path, with the limits explained.
