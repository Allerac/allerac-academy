# Allerac Academy: course map

A hands-on, "start working today" course on AI-assisted development. You learn by doing, from day one, and finish contributing to real Allerac projects.

> Modules are written as the course moves forward. For now, modules 0, 1, 2, 3 and 4 are complete.

## Module 0: First day at work

Use AI to solve something real, get a GitHub account and a first repository, make your first commit and open your first issue. All from a browser or a phone, with nothing to install.

## Module 1: AI beyond chat

What a language model, a prompt, context and an agent are. Why AI makes things up and how to check what it gives you. The difference between a chat (like ChatGPT or Claude) and an agent that works on files (like Claude Code and Codex).

## Module 2: Setup and where code lives

Files and folders, the terminal without fear, the basic commands and a code editor in the browser (GitHub Codespaces, with VS Code on your computer as an option). Open your repository, change something with AI's help and see the result running.

The main path is on a computer. On a tablet or phone, the terminal, editor and "see it run" lessons have an alternative path, with the limits explained (for example, the github.dev editor has no terminal).

*Includes basic security: not pasting passwords or personal data into AI, and turning on two-factor authentication on GitHub.*

## Module 3: Collaboration

Well-written commits, branches, pull requests and code review. Resolving a conflict with AI's help and talking with the team inside GitHub.

*Includes reading and understanding code you did not write, with AI explaining it.*

## Module 4: Development cycle

From ticket to deploy: breaking a task into small steps, working on a branch, testing, asking for review, merging and following up on the result. The basics of how a team organizes itself (backlog and priorities).

## Module 5: Testing

Testing by hand with a script and writing a good bug report. What automated tests are, asking AI to write a test and checking that it makes sense, and understanding why a test breaks in CI (the automatic check that runs on every change).

*Includes debugging: reading an error message and finding the cause.*

## Module 6: Servers

What a server, the cloud, Docker and a deploy are. Environment variables and secrets, and how to read logs when something goes wrong. At the end, putting a small project online.

*Includes security: how to keep keys and secrets.*

## Module 7: Real project

A sequence of Allerac tasks, from the simplest to the most complex: testing, documenting, fixing a text, a small bug and a small feature, using everything from the previous modules.

*Ends with your portfolio: an organized GitHub and your work explained, to show as real experience.*
