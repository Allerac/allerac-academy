# 2.1 Onde as coisas moram

## Problema

Você salvou um arquivo agora há pouco, fechou a janela e... sumiu. Está em Downloads? Na Área de Trabalho? Numa pasta cujo nome você não lembra? Como você explicaria, para outra pessoa achar esse arquivo, exatamente onde ele está?

*Tente pensar numa resposta antes de seguir.*

## Blocos

### 1. Arquivos moram em pastas
Um arquivo é um pedaço de informação com um nome: um texto, uma foto, a sua página `index.html`. Uma pasta (também chamada de diretório) é um lugar para agrupar arquivos. Quando um arquivo "some", quase sempre ele está numa pasta que você não está olhando.

> **Notas para o tutor:** quase todo mundo já perdeu um arquivo. Use essa experiência. Não comece por caminhos ainda.

### 2. Pastas dentro de pastas
Pastas podem ter outras pastas dentro. É como caixas dentro de caixas, ou cômodos dentro de uma casa. O seu repositório `my-academy-journal` é uma pasta: dentro dela estão o `README.md` e o `index.html`.

> **Notas para o tutor:** analogia da casa ou das caixas. Se o aluno já criou subpastas no celular ou no computador, ligue com isso.

### 3. A extensão diz o tipo
A parte depois do ponto no nome do arquivo é a extensão. Ela dá uma dica do que o arquivo é:
- `.md` é um texto em Markdown (como o README)
- `.html` é uma página web
- `.jpg` ou `.png` é uma imagem
- `.txt` é um texto simples

O nome do arquivo e a extensão são em inglês no mundo do software. Você não precisa decorar uma lista: quando tiver dúvida, pergunte à IA o que aquela extensão significa.

> **Notas para o tutor:** reforce que a extensão é parte do nome, não um "enfeite". Erro comum: apagar ou trocar a extensão e o arquivo "quebrar". Não aprofunde tipos MIME.

### 4. O caminho é o endereço
Um caminho (em inglês, *path*) é o endereço completo até o arquivo: a sequência de pastas, da "casa" até o cômodo, até o objeto. Por exemplo, no seu repositório, o caminho do arquivo da página é `index.html` (ele está na pasta principal). Se estivesse numa pasta `pages`, o caminho seria `pages/index.html`.

As barras separam as pastas. É assim que você (e o computador, e a IA) encontram as coisas.

> **Notas para o tutor:** mostre o caminho no GitHub: ao abrir um arquivo, a trilha no topo (repositório / arquivo) é o caminho. Não precisa explicar caminho absoluto vs relativo agora, a menos que o aluno pergunte. No GitHub a barra é sempre `/`.

## Missão

1. Abra o seu repositório `my-academy-journal` no GitHub (no computador, no tablet ou no celular).
2. Liste os arquivos que você vê na pasta principal.
3. Escreva o caminho do `index.html` e diga o que as extensões `.md` e `.html` significam.
4. Conte ao tutor, com suas palavras, como você explicaria a alguém onde esse arquivo mora.

**Como o tutor confere:** o aluno lista os arquivos do repositório, acerta o caminho do `index.html` e explica, mesmo que de forma simples, o que são as duas extensões.
