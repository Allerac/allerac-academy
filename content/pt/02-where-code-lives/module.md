# Módulo 2: Configuração e onde o código vive

## Objetivo

No fim deste módulo, você vai:
- saber o que são arquivos, pastas, extensões e caminhos;
- usar os comandos básicos do terminal com segurança (pedindo para a IA explicar antes de rodar);
- abrir o seu repositório `my-academy-journal` num editor de código;
- mudar a sua página com a ajuda da IA, ver o resultado e guardar a nova versão;
- saber o que nunca colar numa IA e ter ativado a verificação em duas etapas no GitHub.

O caminho principal é no computador, com o editor no navegador (GitHub Codespaces), sem instalar nada. O VS Code no computador é opcional.

Se você estiver no tablet ou no celular, dá para acompanhar: as lições 2.2, 2.3 e 2.4 têm um caminho alternativo marcado **Pelo tablet ou celular**. No tablet, o Codespaces funciona no navegador (melhor com um teclado). No celular a tela fica apertada, então usamos o editor do GitHub e o github.dev, com honestidade sobre o que não dá para fazer (por exemplo, não há terminal no github.dev).
