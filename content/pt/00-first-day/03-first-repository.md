# 0.3 Meu primeiro repositório

## Problema

Você quer guardar o que está aprendendo e deixar que outra pessoa veja e sugira melhorias. Onde você guardaria?

## Blocos

### 1. O que é um repositório
Um repositório (ou "repo") é a pasta de um projeto no GitHub. Ele guarda os arquivos e todo o histórico de mudanças.

> **Notas para o tutor:** analogia: uma pasta com memória. Ela lembra de tudo o que já esteve dentro dela.

### 2. O que é um README
O README é o arquivo de apresentação do repositório. É a primeira coisa que alguém vê ao abrir o projeto: o que é, para que serve e como usar.

> **Notas para o tutor:** mostre o README do allerac-academy como exemplo real.

### 3. O que é um commit
Um commit é uma "foto" do trabalho num certo momento, com uma mensagem explicando o que mudou. O histórico do repositório é a lista de todos os commits.

Uma boa mensagem de commit é curta e diz o que você fez: "Add introduction to README", e não "mudanças".

> **Notas para o tutor:** mensagens de commit são em inglês, como todo o resto do código. Erro comum: mensagens vagas como "update" ou "fix".

### 4. Por que em inglês
No mundo do software, código e documentação de código são escritos em inglês, para qualquer pessoa do mundo entender. Você não precisa ser fluente: a IA ajuda.

> **Notas para o tutor:** tranquilize o aluno. Incentive usar a IA para revisar o inglês.

## Missão

1. Crie um repositório chamado `my-academy-journal`, marcando a opção de adicionar um README.
2. Edite o README pelo navegador e escreva 3 linhas em inglês sobre você e por que está fazendo o curso (pode pedir ajuda à IA).
3. Salve com um commit de mensagem clara, por exemplo `Add introduction to README`.
4. Mande para o tutor o link do repositório.

**Como o tutor confere:** o repositório existe, o README tem 3 linhas em inglês e o commit tem uma mensagem clara.
