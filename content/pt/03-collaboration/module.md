# Módulo 3: Colaboração

## Objetivo

No fim deste módulo, você vai:
- escrever commits que contam o que mudou e por quê;
- trabalhar numa branch sem mexer na versão que funciona;
- abrir um pull request, revisar e receber revisão com gentileza;
- resolver um conflito com a ajuda da IA, decidindo você o resultado;
- ler código que você não escreveu, com a IA explicando;
- abrir o seu primeiro pull request de verdade num projeto da Allerac.

O caminho principal continua no computador, com o GitHub Codespaces. Quase tudo neste módulo também funciona no site do GitHub, então cada lição tem um caminho **Pelo tablet ou celular**, com os limites explicados.
