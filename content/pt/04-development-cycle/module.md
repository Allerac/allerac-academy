# Módulo 4: Ciclo de desenvolvimento

## Objetivo

No fim deste módulo, você vai:
- enxergar o caminho inteiro de uma mudança, do ticket até estar no ar;
- escrever uma tarefa clara, com o que conta como "pronto";
- quebrar uma tarefa em passos pequenos, com a ajuda da IA;
- fazer o trabalho numa branch e testar antes de pedir revisão;
- fazer o merge, conferir o resultado e fechar o ciclo;
- organizar um backlog e decidir o que vem primeiro.

O caminho principal continua no computador, com o GitHub Codespaces. Issues, pull requests e quadros de projeto funcionam no site do GitHub, então cada lição tem um caminho **Pelo tablet ou celular**, com os limites explicados.
