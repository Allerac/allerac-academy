# 1.4 Chat ou agente?

## Problema

Você tem uma pasta com 200 fotos chamadas "IMG_0001.jpg", "IMG_0002.jpg"... e quer renomear todas com a data. Você pede ajuda num chat de IA. Ela te dá instruções. Mas quem vai renomear as 200 fotos?

## Blocos

### 1. O chat responde
Num chat, a IA te entrega texto: uma explicação, um e-mail, um trecho de código. Quem copia, cola e executa é você.

> **Notas para o tutor:** é o que o aluno já fez nas lições anteriores.

### 2. O agente faz
Um agente é uma IA que pode usar ferramentas: ler e criar arquivos, rodar comandos, pesquisar. Você descreve o objetivo, e ele executa os passos, confere o resultado e corrige se der errado.

> **Notas para o tutor:** analogia: o chat é um colega que te explica pelo telefone como fazer. O agente é um colega que senta no seu computador e faz, enquanto você acompanha.

### 3. Agentes de código
O Claude Code e o Codex são agentes feitos para programar. Eles leem os arquivos do projeto, escrevem código, rodam testes e explicam o que fizeram. É com eles que você vai trabalhar nos projetos da Allerac.

> **Notas para o tutor:** o aluno vai instalar e usar um agente de código no módulo 2. Aqui é só o conceito. Não confunda com o chat do Claude.

### 4. Mais poder, mais cuidado
Um agente mexe de verdade nos seus arquivos. Por isso:
- Peça para ele explicar o plano antes de fazer.
- Revise o que ele mudou.
- Trabalhe com controle de versão (GitHub), para poder voltar atrás.

> **Notas para o tutor:** ligue com o módulo 0: o histórico do GitHub é a rede de segurança para trabalhar com agentes.

## Missão

Para cada tarefa abaixo, diga ao tutor se um chat basta ou se um agente seria melhor, e por quê:
1. Escrever um convite de aniversário.
2. Corrigir um erro que aparece em 15 arquivos de um projeto.
3. Entender o que significa uma mensagem de erro.
4. Criar um site com 5 páginas e publicar.

**Como o tutor confere:** o aluno identifica que tarefas que mexem em muitos arquivos ou exigem executar coisas pedem um agente (2 e 4), e justifica.
