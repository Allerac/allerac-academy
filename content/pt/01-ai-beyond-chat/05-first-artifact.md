# 1.5 Meu primeiro artefato

## Problema

Você quer uma página na internet para se apresentar, mas não sabe programar. Quanto tempo leva para ter uma?

## Blocos

### 1. O que é um artefato
Um artefato é algo concreto que a IA cria para você: uma página web, um documento ou um diagrama. Se a ferramenta oferecer uma prévia, como o recurso Artifacts do Claude, você pode conferir o resultado ali.

> **Notas para o tutor:** mostre que artefato não é só código: é qualquer coisa que se usa ou se publica.

### 2. Uma página web é um arquivo
Uma página web simples é um arquivo de texto chamado HTML. O navegador lê esse arquivo e mostra a página. Você não precisa entender cada linha agora: precisa saber pedir e conferir.

> **Notas para o tutor:** não ensine HTML. Se o aluno ficar curioso, peça para a IA explicar uma parte do arquivo.

### 3. Iterar
Raramente a primeira versão é a final. Peça ajustes: cores, textos, uma seção nova. Cada pedido é uma iteração.

> **Notas para o tutor:** ligue com a lição 0.1: pedir ajustes é o fluxo normal.

### 4. Guardar com histórico
O arquivo criado pela IA vai para o seu repositório, com um commit. Assim você guarda cada versão da sua página.

> **Notas para o tutor:** no módulo 4, essa página vai para o ar num servidor. Pode mencionar como "spoiler".

## Missão

1. Peça à IA: "Crie uma página web simples, em um único arquivo HTML, para me apresentar." Diga seu nome, o que você gosta e por que está aprendendo tecnologia.
2. Peça pelo menos 2 ajustes.
3. Salve o resultado como `index.html`. Se a IA só mostrar o código, no GitHub escolha **Add file → Create new file**, dê o nome `index.html` e cole o HTML. Se tiver baixado o arquivo, use **Add file → Upload files**.

   Abra o arquivo salvo no navegador ou confira a prévia, se estiver disponível. No celular, se não conseguir abrir a página, confira o HTML e teste a página quando tiver acesso a um computador.
4. Faça o commit com uma mensagem clara, por exemplo `Add personal web page`.
5. Mande ao tutor o link do arquivo no GitHub.

**Como o tutor confere:** o arquivo `index.html` está no repositório, com um commit de mensagem clara, e o aluno conta quais ajustes pediu.
