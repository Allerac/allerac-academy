# Roadmap

## Now

Focus on a single beginner student.

1. Course format and course map (done).
2. Module 0 in Portuguese.
3. Module 1 in Portuguese.
4. The learning app (`app/`) and the AI tutor (`tutor/`).
5. Remaining modules, written on demand as the student progresses.
6. English and Spanish translations of each approved module.

## Parked ideas (later)

- **Onboarding for anyone joining Allerac.** The Academy becomes the official entry path for new contributors.
- **Entry tests per module.** Each module starts with a practical challenge; whoever solves it can skip the module.
- **Multiple entry points by level:**
  - career changers start at Module 0;
  - developers who do not use AI start at Module 1;
  - experienced people go straight to the real project, with a short Allerac onboarding.
- **Videos produced by Allerac**, at least short screen recordings for some missions.
- **Formalizing contributions** (internship or service contract) so students can list Allerac as work experience.
