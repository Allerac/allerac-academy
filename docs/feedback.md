# Student Feedback

> Status: **proposed**. Updated as we learn.

Feedback tells us where the course fails to explain something. Every signal points to a specific block, so we know exactly what to rewrite.

## Layers

### 1. "Didn't get it" button
- Shown on every block.
- One tap; no text required.
- Records: lesson, block, timestamp.

### 2. Automatic tutor signals
The AI tutor records a weak spot when:
- the student asks "explain better" on the same block more than once;
- the student fails the same mission more than once;
- the student abandons a lesson midway.

### 3. End-of-lesson check
Two quick questions:
- "What was hardest?" (free text, optional)
- "How clear was this lesson?" (1 to 5)

## What we do with it

All signals feed a single review list, grouped by block and sorted by how often they appear. We regularly review the list and rewrite the blocks, tutor notes, or missions that are not working.

## Bonus: feedback as practice

In Module 0, the student's first contribution is opening a GitHub issue with feedback about the course. Feedback is both a course signal and a real exercise.
