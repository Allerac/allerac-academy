# Allerac Academy

A hands-on, "start working today" course on AI-assisted software development. Students learn by doing real work from day one and finish able to contribute to real Allerac projects.

## Repository structure

```
docs/       Project documentation (English)
content/    Course content
  pt/       Portuguese (written first)
  en/       English (translated after approval)
  es/       Spanish (translated after approval)
app/        The learning app (coming soon)
tutor/      AI tutor prompts and rules (coming soon)
```

## Start here

- [Course format](docs/course-format.md): principles, lesson structure, and feedback.
- [Course map (pt)](content/pt/course.md): all modules at a glance.

## Languages

Course content is available in Portuguese, English, and Spanish. Code, code comments, code documentation, and folder and file names are always in English.
