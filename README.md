# Allerac Academy

A hands-on, "start working today" course on AI-assisted software development. Students learn by doing real work from day one and finish able to contribute to real Allerac projects.

## Repository structure

```
docs/       Project documentation (English)
content/    Course content
  pt/       Portuguese (written first, the source for translations)
  en/       English
  es/       Spanish (neutral, for Spain and Latin America)
app/        The learning site: Cloudflare Worker + static assets (see app/README.md)
tutor/      AI tutor prompts and rules (English)
```

## Start here

- [Course format](docs/course-format.md): principles, lesson structure, and feedback.
- Course map: [pt](content/pt/course.md), [en](content/en/course.md), [es](content/es/course.md).

## Languages

Course content is available in Portuguese, English, and Spanish, with the same folders, file names and lesson ids in each language. The site picks the language from the browser (falling back to Portuguese) and has a PT / EN / ES switcher. Code, code comments, code documentation, and folder and file names are always in English.
